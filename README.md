# YMM4 ストップモーションプラグイン

ゆっくりMovieMaker4（YMM4）で、撮影した写真を1コマずつ並べてストップモーション（コマ撮り）アニメーションを作るための図形プラグインです。

## できること

- **画像の取り込み**
  - 「画像を追加...」：ファイルを複数選んで追加
  - 「フォルダから追加...」：フォルダ内の画像をファイル名順にまとめて追加
  - エクスプローラーからファイル／フォルダをドラッグ＆ドロップで追加
  - 追加したものは選択中のコマの後ろに入ります
  - ファイル名順は `IMG_2.jpg` → `IMG_10.jpg` のように数字を数値として並べます（カメラの連番順）
  - ▲▼ で並べ替え、✕ / Delete キーで削除、「ファイル名順に並べ替え」「すべて削除」
  - 選択中のコマのプレビュー、コマ数・再生時間の表示
- **フレームレート（fps）の設定**：1秒あたりに表示するコマ数（0.1〜240fps、初期値 12fps）。プロジェクトのフレームレートとは別に指定できます
- **再生終了後の動作**：ループ／最後のコマで停止／往復
- 撮り直してファイルを上書きした場合は、自動で読み込み直します
- Undo / Redo、複数アイテムの同時編集に対応

## 使い方

1. タイムラインに **図形アイテム** を追加する
2. アイテム編集エリアで **図形の種類** を「**ストップモーション**」にする
3. 「画像を追加...」「フォルダから追加...」またはドラッグ＆ドロップでコマ画像を追加する
4. 「フレームレート」を設定する
5. アイテムの長さを、一覧の上に表示される再生時間（例：`24 コマ　12 fps で 2 秒`）に合わせる

画像は原寸（1px = 1px）で中央に表示されます。カメラの写真は画面より大きいことが多いので、図形アイテムの「拡大率」で調整してください。

## ビルド方法

必要なもの：YMM4 v4.47.0.0 以降、.NET 10 SDK（Visual Studio 2022/2026 など）

1. `Directory.Build.props.sample` をコピーして `Directory.Build.props` という名前で保存する
2. `Directory.Build.props` の `YMM4DirPath` を YMM4 のインストールフォルダ（`YukkuriMovieMaker.exe` があるフォルダ）に書き換える（末尾の `\` を忘れずに）
3. `YmmStopMotion.sln` を開いて `YmmStopMotion` をビルドする
   ```bash
   dotnet build YmmStopMotion/YmmStopMotion.csproj -c Release
   ```
4. ビルドすると `YMM4フォルダ\user\plugin\YmmStopMotion\YmmStopMotion.dll` に自動でコピーされます
5. YMM4 を起動し、`設定` → `プラグイン` → `プラグイン一覧` に表示されていれば読み込み成功です

### デバッグ

`YmmStopMotion` のデバッグプロパティで「実行可能ファイル」に `YukkuriMovieMaker.exe` を指定すると、ブレークポイントを使ってデバッグできます。
YMM4 の `設定` → `開発者モード` を有効にすると、DirectX オブジェクトの解放漏れを検出できます。

### テスト

YMM4 に依存しないロジック（コマ番号の計算・ファイル名の並べ替えなど）はテストがあり、YMM4 がない環境でも実行できます。

```bash
dotnet test tests/YmmStopMotion.Tests
```

## 配布

ビルドした `YmmStopMotion.dll` を zip で圧縮し、拡張子を `.ymme` に変更すると、YMM4 にワンクリックでインストールできる形式になります。

## 構成

```
YmmStopMotion/
├─ StopMotionShapePlugin.cs      プラグイン本体（図形の種類「ストップモーション」）
├─ StopMotionShapeParameter.cs   設定項目（コマ画像・フレームレート・再生終了後）
├─ StopMotionShapeSource.cs      再生位置に応じたコマの描画
├─ Rendering/FrameBitmapCache.cs 画像の読み込み（WIC）とキャッシュ
├─ Views/                        コマ画像一覧の編集UI
└─ Core/                         YMM4 に依存しないロジック
tests/YmmStopMotion.Tests/       Core のテスト
```

## 現時点の制限

- 画像はプロジェクトにフルパスで保存されます。画像を移動・リネームすると表示されなくなります（一覧で取り消し線になります）
- 写真の EXIF の回転情報は反映されません（縦向きで撮った写真が横向きになる場合があります）
- 読み込んだ画像は最大 512MB 分までメモリ（VRAM）に保持します。高解像度の写真を大量に使う場合はあらかじめ縮小しておくと再生が軽くなります
- exo 出力（AviUtl）には対応していません

## 今後のアイデア

- コマごとの表示時間（同じコマを長く見せる「n コマ打ち」）
- オニオンスキン（前後のコマを半透明で重ねて確認）
- 読み込み時の縮小、EXIF 回転の反映
- アイテムの長さを全コマ分に合わせる機能
